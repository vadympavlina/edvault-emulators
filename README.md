# Емулятори Edvault

Навчальні симулятори для уроків — Windows, блогер, місто й стартап. Статичні сторінки: HTML, CSS і модулі JavaScript,
що відкриваються в браузері як є. Збирати нічого не треба, зовнішніх бібліотек немає.
Ті самі емулятори працюють на сайті [edvault.online](https://www.edvault.online/emulators/windows).

| Сторінка | Код | Що це |
|---|---|---|
| `windows.html` | `windowsemu/` | Емулятор Windows: Провідник, командний рядок, Блокнот, Диспетчер завдань, мережа, роутер, брандмауер, антивірус. На телефоні показує, що потрібен комп'ютер чи планшет |
| `blogger.html` | `bloggeremu/` | Симулятор блогера: телефон із соцмережею, відеоплатформою й месенджером, власні фото й відео, реклама |
| `city.html` | `citysim/` | Симулятор міста: ізометрична мапа, бюджет, транспорт, екологія, жителі, місії |
| `startup.html` | `startupsim/` | Симулятор стартапу: п'ять етапів, своя ідея, клієнти, продукт, реклама, гроші, команда, інвестори; простий і повний режими |
| `index.html` | — | Головна сторінка з усіма емуляторами |

Спільне: `shared/savefile.js` (збереження гри у файл, назва файлу, контрольна сума) і `shared/zip.js` (ZIP без бібліотек — для блогера).
Шрифти симулятора стартапу лежать локально в `startupsim/fonts/` (ліцензія SIL OFL, див. README там).

## Запуск

```bash
npm start          # http://localhost:8080 — локальний сервер, адреси без .html (як на GitHub Pages)
npm test           # перевірки логіки в Node, без браузера
npm run test:e2e   # браузерні тести (потрібні Playwright і Chromium)
npm run test:e2e -- startup   # лише тести, у назві яких є «startup»
```

Залежностей встановлювати не треба. Браузерним тестам потрібні `playwright` і Chromium
(шляхи — змінні `PLAYWRIGHT_MODULE` і `CHROME`). Спільний помічник — `tests/_harness.mjs`.

## Розміщення

Репозиторій готовий для GitHub Pages: Settings → Pages → Deploy from a branch → `main`, тека `/ (root)`.
Усі шляхи відносні, тож сайт працює й у підпапці (`https://<користувач>.github.io/edvault-emulators/`).
Файл `.nojekyll` вимикає обробку Jekyll.

## Домовленості

- Інтерфейс український, звертання на «ви», нейтральний рід до учнів. Без емодзі в інтерфейсі.
- Працює без реєстрації: дані — у браузері (localStorage, IndexedDB) і в файлах, які учень зберігає сам.
- Усі люди, компанії й сайти всередині емуляторів вигадані.
